Bus Stops Within 500 Metres of Greyfriars Bobby

This project was completed as part of the KijaniHub GIS Fundamentals course.

The aim was to identify bus stops located within 500 metres of Greyfriars Bobby in Edinburgh using QGIS.

Methods
1. Created a point layer for Greyfriars Bobby
2. Downloaded bus stop data from OpenStreetMap
3. Reprojected data to EPSG:32630
4. Created a 500m buffer
5. Clipped bus stops to the buffer
6. Counted bus stops within the study area

Results
34 bus stops were identified within 500 metres of Greyfriars Bobby.

Software used
QGIS
OpenStreetMap
Overpass Turbo
